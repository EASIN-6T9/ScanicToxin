# ScanicToxin
ScanicToxin is a Simple Qr Code Making Tool, Also You Can Make a Phishing Qr image using phishing url...“This Tool is made for educational purposes”.

<h1>Installation ⚫</h1>

```
termux-setup-tools
pkg update -y
pkg upgrade -y
pkg install python -y
pkg install python-pip
pkg install git -y
git clone https://github.com/ScanicToxin
cd ScanicToxin
pip install termcolor
pip install colorama
pip install qrcode
pkg install libjpeg-turbo
pip install --no-cache-dir --no-binary :all: Pillow
```
<h2>Run Cmd</h2>
```python ScanicToxin.py
```
